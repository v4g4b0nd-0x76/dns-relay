# Developer Guide

This repo is a Rust workspace with a Tauri GUI. Start here when changing code so
you can find the right file before editing.

## Project Map

| Path | Purpose |
| --- | --- |
| `dns_relay/` | Main DNS relay binary, config parsing, resolver selection, cache behavior, DNS handling, metrics, and query history. |
| `resolver_proxy/` | Optional local UDP proxy and obfuscated UDP client side. |
| `shared/` | Shared DNS packet helpers, cache primitives, rule matching, history/log support, and network guard code. |
| `dns_relay_admin/` | Privileged helper used by the GUI to install, repair, start, stop, and apply system service config. |
| `gui/` | Desktop GUI frontend and Tauri shell. |
| `assets/` | Service templates, relay worker assets, and platform support docs. |
| `scripts/` | Release builds, GUI sidecar staging, and install scripts. |
| `.github/workflows/` | CI, release, and crates.io publishing workflows. |

## Desktop GUI

The GUI is split into a small TypeScript frontend and a Rust Tauri backend.

| Path | Change this when... |
| --- | --- |
| `gui/src/render.ts` | You change visible screens, labels, sections, forms, cards, or empty states. |
| `gui/src/styles.css` | You change layout, spacing, responsive behavior, colors, button sizing, or visual polish. |
| `gui/src/store.ts` | You change client state transitions, dirty tracking, fixtures, or frontend command orchestration. |
| `gui/src/events.ts` | You add or change UI event handlers. |
| `gui/src/backend.ts` | You change the frontend API wrapper around Tauri commands. |
| `gui/src/types.ts` | You change shared frontend types. |
| `gui/src/config-fields.json` | You expose a new config field in the GUI. Keep it in sync with serialized config leaves. |
| `gui/tests/app.spec.mjs` | You change production GUI behavior or layout. Add a focused regression here. |
| `gui/tests/prototype.spec.mjs` | You change the static prototype. |
| `gui/prototype/` | You update the standalone prototype only. Do not treat it as production GUI code. |
| `gui/src-tauri/src/commands.rs` | You change Tauri commands, validation, config apply, service actions, resolver tests, import/export, or adoption. |
| `gui/src-tauri/src/observability.rs` | You change health, metrics, logs, history, or telemetry error behavior. |
| `gui/src-tauri/src/secrets.rs` | You change secret storage behavior and masking. |
| `gui/src-tauri/src/vault.rs` | You change encrypted fallback vault behavior. |
| `gui/src-tauri/src/state.rs` | You change initial app state, recovery, or installed-config adoption state. |
| `gui/src-tauri/src/tray.rs` | You change tray menu behavior. |
| `gui/src-tauri/tauri*.conf.json` | You change bundle metadata, platform bundle settings, windows, icons, or sidecars. |

Do not edit `gui/dist/` by hand. It is generated by `npm run build`.

## Privileged Service Flow

The GUI does not run arbitrary shell commands. It calls fixed Tauri commands,
which create fixed `dns_relay_admin` requests. The admin helper owns privileged
system changes.

| Layer | Main files |
| --- | --- |
| Frontend action | `gui/src/events.ts`, `gui/src/store.ts` |
| Tauri command | `gui/src-tauri/src/commands.rs` |
| Admin protocol | `dns_relay_admin/src/lib.rs`, `dns_relay_admin/src/main.rs` |
| Config apply and rollback | `dns_relay_admin/src/apply.rs` |
| Linux service install/control | `dns_relay_admin/src/platform/linux.rs` |
| macOS service install/control | `dns_relay_admin/src/platform/macos.rs` |
| Fixed install paths | `dns_relay_admin/src/paths.rs` |

When changing apply/install/repair behavior, add or update tests in
`dns_relay_admin/src/tests.rs` and `gui/src-tauri/src/commands_tests.rs`.

## Build And Test

Run the Rust workspace checks:

```bash
cargo fmt --all -- --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

Run the GUI checks:

```bash
cd gui
npm test -- --workers=1
npm run build
npm run tauri build
```

Build platform GUI packages from the repo root:

```bash
make gui-linux       # Linux .deb and .rpm
make gui-linux-test  # Linux package build plus Playwright tests
make gui-mac         # macOS app bundle on macOS
```

Reinstall the freshly built GUI package:

```bash
make gui-install       # picks Linux or macOS
make gui-linux-install # Linux .deb
make gui-mac-install   # /Applications/DNS Relay.app
```

On Linux, Tauri needs native development packages before Rust can compile the
GUI crate:

```bash
sudo apt-get update
sudo apt-get install -y build-essential libayatana-appindicator3-dev libglib2.0-dev librsvg2-dev libssl-dev libwebkit2gtk-4.1-dev libxdo-dev pkg-config
```

## Common Change Checklist

| Change | Minimum checks |
| --- | --- |
| DNS packet/rule/cache behavior | `cargo test -p dns-relay-shared`, `cargo test -p dns_relay` |
| Resolver or relay behavior | `cargo test -p dns_relay resolver`, plus focused client/relay tests |
| Admin helper or service management | `cargo test -p dns_relay_admin`, `cargo clippy -p dns_relay_admin --all-targets -- -D warnings` |
| Tauri command behavior | `cargo test -p dns_relay_gui`, `cargo clippy -p dns_relay_gui --all-targets -- -D warnings` |
| GUI layout or interaction | `cd gui && npm test -- --workers=1`, `cd gui && npm run build`, and inspect a screenshot. |
| Package/install flow | `make gui-linux-test` on Linux or `make gui-mac-install-test` on macOS. |
| Release workflow | `make patch`, `make minor`, or `make major`; use `PUSH=1` only when ready to publish. |

## CI Notes

`cargo test --workspace` includes `gui/src-tauri`, so Ubuntu CI must install the
Linux GUI packages listed above before Rust builds. If CI fails in `glib-sys`,
`gio-sys`, `gobject-sys`, WebKitGTK, appindicator, OpenSSL, or xdo crates, check
`.github/workflows/test.yml` and `.github/workflows/publish-crates.yml` first.

The release workflow in `.github/workflows/release.yml` builds CLI artifacts for
Linux, macOS, and Windows. GUI package automation is currently local Makefile
driven.

## Generated And Staged Files

`scripts/stage_gui_sidecars.sh` copies release `dns_relay` and
`dns_relay_admin` binaries into `gui/src-tauri/binaries/` and writes their
SHA-256 files. Tauri consumes those staged sidecars during bundle builds.

Generated outputs are not source:

- `target/`
- `gui/dist/`
- `gui/test-results/`
- `gui/src-tauri/logs/`

Rebuild them from source instead of editing them.
